# Настройка VK Mini App (пошагово)

## Шаг 1. Создайте приложение VK

1. Зайдите на [vk.com/dev](https://vk.com/dev).
2. Нажмите **My Apps** → **Create an app**.
3. Выберите тип: **Embedded app (VK Mini App)**.
4. Введите название (например, "Конкурс").
5. Загрузите иконку (512x512 px).
6. Нажмите **Create**.

## Шаг 2. Настройте URL

1. В настройках приложения найдите раздел **App settings**.
2. Поле **Redirect URL** — пока не нужно (для OAuth).
3. Поле **App URL** (или VK Mini App URL):
   - Для локальной разработки: `http://localhost:3000/vk-astro-contest`
   - Для продакшна: `https://ВАШ_НИК.github.io/vk-astro-contest/`
4. Сохраните.

## Шаг 3. Скопируйте ID приложения

1. В настройках найдите **App ID** (число).
2. Вставьте в `.env.local` → `NEXT_PUBLIC_VK_APP_ID`.

## Шаг 4. Получите Service Token (для проверки репостов)

1. В настройках приложения найдите **Service token**.
2. Скопируйте его.
3. Вставьте в Apps Script Properties:
   - Файл → Свойства проекта → Свойства скрипта → `VK_SERVICE_TOKEN`.

## Шаг 5. Подключите VK Bridge

VK Bridge уже подключён в коде (`@vkontakte/vk-bridge`).
Инициализация идёт автоматически в `src/components/common/Providers.tsx`.

## Шаг 6. Тестирование внутри VK

### В мобильном приложении VK

1. Откройте VK на телефоне.
2. Зайдите в **Мини-приложения** (или найдите ваше приложение).
3. Откройте его — VK Bridge заработает.

### В веб-версии VK

1. Откройте [vk.com](https://vk.com) на компьютере.
2. Перейдите в раздел с вашим приложением.

### Локально (вне VK)

VK Bridge не работает вне VK. Для локальной разработки:
```
NEXT_PUBLIC_MOCK_MODE=true npm run dev
```
В mock-режиме VK Bridge не вызывается, отдаются тестовые данные.

## Шаг 7. Публикация

1. Когда приложение готово и задеплоено на GitHub Pages:
   - Укажите в настройках VK приложения URL продакшна.
2. Отправьте на модерацию (если нужно публичное приложение).
3. После одобрения — приложение доступно всем пользователям VK.

## Частые проблемы

### VK Bridge не отвечает

- Проверьте, что вы внутри VK (приложение или vk.com).
- Вне VK используйте mock-режим.
- Проверьте консоль браузера (F12) на ошибки.

### Ошибка "VKWebAppGetUserInfo failed"

- Пользователь не авторизован в VK.
- Приложение не добавлено в настройки VK.
- Проверьте App ID.

### Репост не проверяется

- Не задан `VK_SERVICE_TOKEN` в Apps Script Properties.
- Метод `checkRepost` возвращает false — показывается модалка.
- Для теста включите mock-режим (репост считается сделанным).
